# AGENTS.md

This project is Claude-first. CLAUDE.md is the primary instruction file and source of truth for all shared workflow. GitHub Copilot is supported on a best-effort basis.

Skill wrappers route from `.github/skills/<name>/SKILL.md` to `.claude/skills/<name>/SKILL.md`. Agent wrappers route from `.github/agents/<name>.agent.md` to `.claude/agents/<name>.md`.
